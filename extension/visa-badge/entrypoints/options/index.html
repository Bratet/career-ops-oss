Visa Badge: Jev

Paste your OpenRouter API key to classify postings with Jev (typesafe/jev-1.13): visa sponsorship, and whether remote jobs accept people outside Europe. Each posting is classified once and cached for two weeks.


    
Stored only in this browser (chrome.storage.local). Get a key at openrouter.ai/settings/keys. Jev costs about $0.00005 per posting.
